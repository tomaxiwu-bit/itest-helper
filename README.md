# iTest Helper · 答案导入与填写工具

把你已经整理好的答案数组导入 iTest 页面，先核对题目数量，再填写当前页或按顺序逐页填写。适用于减少重复点击与录入；答案需要自行准备，脚本不生成答案，也不自动交卷。

*A userscript for importing your own answers into iTest pages.*

**[安装脚本](https://raw.githubusercontent.com/tomaxiwu-bit/itest-helper/master/itest-helper.user.js)** · [操作步骤](#先填写当前页再处理全部) · [答案格式](#答案格式) · [源代码](itest-helper.user.js)

## 一次操作会发生什么

```text
准备 JSON 答案 → 扫描当前页 → 保存答案 → 填写当前页核对 → 从第一页处理全部
```

| 按钮 | 作用 |
|---|---|
| 扫描题目 | 检查当前页可识别题目数，便于与答案核对 |
| 保存答案 | 将输入保存在脚本管理器的本地存储中，下次加载 |
| 填写当前页 | 从答案数组开头匹配当前页，便于先检查填写效果 |
| 全部 | 从当前页开始按已处理题数继续取答案，等待翻页后再填写 |

检测到答案不足、页面切换超时、题目重复或无法匹配时，脚本会停止并提示。当前页答案不足时整页不填，避免部分填写后继续推进。

## 安装

先安装支持用户脚本的浏览器扩展，例如 [ScriptCat](https://docs.scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/)。

1. 点击 [安装 itest-helper.user.js](https://raw.githubusercontent.com/tomaxiwu-bit/itest-helper/master/itest-helper.user.js)。
2. 在脚本管理器弹出的页面确认安装，并检查脚本已启用。
3. 打开匹配的 iTest 答题页面并刷新，查看脚本面板。

若浏览器直接显示源代码，可在脚本管理器中新建脚本，复制 [完整代码](itest-helper.user.js)，替换编辑器内容后保存。

## 先填写当前页，再处理全部

1. 进入答题页，点击“扫描题目”，核对识别数量。
2. 粘贴 JSON 答案并点击“保存答案”。
3. 点击“填写当前页”，逐项核对题序和答案映射。
4. 需要逐页处理时，**回到第一页**，提供覆盖所有页的完整答案数组，再点击“全部”。
5. 完成后仍需人工检查页面内容。脚本不会替你提交。

“填写当前页”每次都从数组开头读取；“全部”没有断点续填语义，不应从中间页配合全卷答案直接启动。重新打开页面会加载此前保存的答案，请先确认仍对应本次内容。

## 答案格式

可以直接使用数组：

```json
["A", "B", "C", "D"]
```

也支持带 `answers` 字段的对象：

```json
{"answers": ["A", "B", "C", "D"]}
```

答案按页面上可识别题目的 DOM 顺序排列，跨页时按页顺序连续排列。示例中的 4 个答案仅表示 4 道题，应按实际题数提供完整内容。

| 选择题答案 | 对应选项 |
|---|---|
| A | 第 1 个，`value=0` |
| B | 第 2 个，`value=1` |
| C | 第 3 个，`value=2` |
| D | 第 4 个，`value=3` |

识别到的文本题会填入对应字符串，并保留文本大小写。当前匹配依赖平台页面结构，不应仅凭字母相同就假设已对应到正确题目。

## 常见问题

**没有出现面板**：检查扩展与脚本是否启用，当前地址是否匹配脚本的 `@match` 规则。主要入口为 `itestcloud.unipus.cn/itest-api/itest/s/answer/index`。

**题数对不上**：先扫描并检查可识别题目，核对数组长度与顺序；不要在未确认映射时直接运行“全部”。

**翻页后停止**：脚本等待题目 ID 切换，最长 10 秒。查看面板提示，确认网络、页面和剩余答案后再操作。

**填写有误**：若正在逐页处理，刷新页面可中断本轮脚本执行，随后人工核对并修正。刷新是否保留已填写答案由平台行为决定，不能将它当作清空方式。重新运行“全部”前，应回到第一页并核对完整答案。

## 开发与设置

翻页上限默认 200，来自脚本管理器存储项 `itest_maxPages`；答案保存在 `my_answers`。需要修改或清理时，使用管理器支持的脚本存储编辑功能，或在脚本自身执行上下文中调用 `GM_setValue`。普通网页控制台通常不能访问这些授权 API。

```javascript
// 在脚本自身的执行上下文中使用
GM_setValue("itest_maxPages", 999);
GM_setValue("my_answers", "");
```

需要 Node.js 才能运行开发检查：

```powershell
npm test
```

检查包括 JavaScript 语法及模拟 DOM 的答案填写、题序和翻页行为；平台改版后的真实页面仍需重新验证。脚本声明采用 MIT 许可。
